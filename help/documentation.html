Getting Started

5 min read Updated Jul 12, 2026 OnePlace Team

Introduction to OnePlace

OnePlace Enterprise is an all-in-one platform designed to streamline your business communications. Whether you're managing customer support, sales pipelines, or team collaboration, OnePlace brings everything together in a single, powerful interface.

Key Features

  • Unified Inbox: Manage all your conversations from Gmail, WhatsApp, Instagram, Slack, and more in one place.
  • CRM Integration: Track leads, manage contacts, and monitor deals without leaving your inbox.
  • AI Assistant: Leverage AI to automate responses, summarize conversations, and extract insights.
  • Workflow Automation: Build custom automations to handle repetitive tasks.
  • Team Collaboration: Assign conversations, leave internal notes, and collaborate in real-time.

Quick Setup

Getting started with OnePlace takes just a few minutes. Follow these steps to set up your workspace:

bash 
# Install OnePlace CLI
npm install -g @oneplace/cli

# Login to your account
oneplace login

# Create a new workspace
oneplace workspace create "My Workspace"

Creating Your Account

To create your OnePlace account, visit our sign-up page and enter your email address. You'll receive a verification code to confirm your identity. Once verified, you can set up your profile and workspace.

Workspace Configuration

Your workspace is the central hub for all your team activities. Configure your workspace settings, invite team members, and set up integrations from the workspace settings panel.

javascript 
// Initialize OnePlace SDK
import { OnePlace } from '@oneplace/sdk';

const client = new OnePlace({
  apiKey: 'your_api_key',
  workspace: 'my-workspace'
});

// Connect a channel
await client.channels.connect('whatsapp', {
  phoneNumber: '+1234567890'
});

Connecting Your First Channel

OnePlace supports multiple communication channels. Start by connecting your most-used channel:

  1. Navigate to Integrations in your sidebar
  2. Select the channel you want to connect (e.g., Gmail, WhatsApp)
  3. Follow the authentication flow
  4. Configure sync settings and filters
  5. Start receiving messages in your Unified Inbox
