API Documentation

Integrate OnePlace with your applications using our REST API.

Getting Started

The OnePlace API is organized around REST. Our API has predictable resource-oriented URLs, accepts JSON request bodies, returns JSON-encoded responses, and uses standard HTTP response codes, authentication, and verbs.

Base URL

https://api.oneplace.com/v1 
https://api.oneplace.com/v1

Authentication

All API requests must include your API key in the Authorization header:

Authorization: Bearer YOUR_API_KEY 
curl https://api.oneplace.com/v1/conversations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"

Authentication

OnePlace uses API keys to authenticate requests. You can view and manage your API keys in your workspace settings.

Webhooks

Webhooks allow you to receive real-time notifications when events occur in your OnePlace workspace.

Event Types

  • conversation.created — Triggered when a new conversation is created
  • message.received — Triggered when a new message is received
  • contact.updated — Triggered when a contact is updated
  • ticket.status_changed — Triggered when a ticket status changes

Webhook Payload

JSON 
{
  "event": "message.received",
  "timestamp": "2026-07-12T10:30:00Z",
  "data": {
    "conversation_id": "conv_123",
    "message_id": "msg_456",
    "content": "Hello, I need help with...",
    "sender": {
      "id": "user_789",
      "name": "John Doe"
    }
  }
}
